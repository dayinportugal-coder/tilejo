# Tilejo – web

Web version (PWA) of Tilejo, by Pedro Carvalho. Free to play, with an optional one-time unlock of the full game (Gumroad licence key). No ads, no account, progress saved in the browser.

The unlock settings (Gumroad product_id and link) are in config.js.

Play: https://dayinportugal-coder.github.io/tilejo/

Privacy: https://dayinportugal-coder.github.io/tilejo/privacy/
